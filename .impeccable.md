# Design Context — Brandon Chen Portfolio

## Users
Engineering recruiters, hiring managers, and professors, often on a phone at a
career fair with 30 seconds to form an impression. Secondary: Brandon himself,
editing content between application cycles.

## Brand Personality
Precise, credible, understated. Three words: **exact, grounded, confident.**
An engineer who lets the work and the numbers talk, and is honest about what is
measured versus estimated. Never flashy, never overclaiming.

## Aesthetic Direction
"Drafting Table" — the visual language of an engineering drawing used as real
interface, not decoration. Warm vellum paper, near-black ink, a single
blueprint-blue accent. ANSI title blocks as project metadata, dimension lines
as dividers, leader lines with arrowheads for quantified results, tabular
figures for spec data. Bricolage Grotesque display, Newsreader body, IBM Plex
Mono for numeric callouts only. Light default, dark ("Night") available.
Anti-references: dark-mode-with-glowing-accents, glassmorphism, uniform rounded
card grids, skill percentage bars, gradient text.

## Design Principles
1. **Credibility over flash.** Evidence beats adjectives; label estimates as estimates.
2. **The drawing is the interface.** Drafting conventions carry real information, never ornament.
3. **One accent, used sparingly.** Blueprint blue marks what matters; everything else is paper and ink.
4. **Degrade gracefully.** Works without JS (content in noscript), without WebGL (download link), on any screen.
5. **One file to edit.** All content in content/portfolio.js so the owner never touches markup.
